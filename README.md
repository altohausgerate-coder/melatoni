# Melatoni

Melatoni is a static storefront for bedding and sleep-related home products.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. The product catalog and page interactions are implemented with HTML, CSS, and vanilla JavaScript.

## Pages

- `index.html` — storefront and product discovery
- `product.html` — product details
- `about.html` — brand story
- `contact.html` — contact information

Product content is maintained in `products-data.js`; product imagery is in `assets/`.
